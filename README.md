# 高考长难句 · 翻译练习

纯静态单页应用，收录 **2718 条高考长难句**（其中 **1972 条为历年高考真题句子**，覆盖 2008–2021 共 14 个年份），每条包含英文原句、中文参考译文、词数、难度分级、从句结构标签与真题来源。核心玩法：**先自己翻译，再点开参考译文核对**。另附**中译英**功能，可把中文在线翻译成英文。全部练习数据保存在浏览器 localStorage，无需后端、无需数据库。

## ✨ 功能

| 模块 | 说明 |
| --- | --- |
| 翻译练习 | 英文长难句卡片，连接词高亮；点「查看参考译文」展开中文；可标记「我理解了 / 需要再看 / 收藏」，自动进入下一句 |
| 历年真题 | 独立页面按年份分组浏览真题句子，年份筛选条可只看某一年；点「练 XXXX 年真题」直接进入该年专项练习 |
| 难度分级 | 按长度自动分为中等（12–15 词）、较难（16–22 词）、困难（23 词以上），可单难度专项练习 |
| 练习范围 | 可切换「全部句库 / 历年真题」，真题范围内再叠加年份过滤 |
| 顺序 / 随机 | 顺序模式按「未练 → 需再看 → 已理解」+ 句子由短到长推送；随机模式可随时抽句 |
| 句库 | 全量浏览，支持英文/中文关键词搜索、难度筛选、状态筛选（未练 / 已理解 / 需再看 / 收藏 / 真题） |
| 中译英 | 输入中文，调用在线翻译服务输出英文；同时给出句库中语义最接近的句子作参考译文 |
| 数据统计 | 已练习 / 已理解 / 需再看 / 已收藏、近 14 天练习量柱状图、难度掌握分布、历年真题练习进度、连续天数 |
| 备份迁移 | 导出 / 导入 JSON 记录，换设备不丢进度 |
| 手机使用 | 右上角分享按钮生成二维码，扫码即可在手机打开 |

## 📚 语料说明

- 共 **2718 句**，其中 **历年真题 1972 句**（`p:1`），覆盖 2008–2021 共 14 个年份
- 真题年份分布：2021（538）、2020（523）、2019（145）、2018（123）、2017（114）、2016（153）、2015（152）、2014（121）、2013（47）、2012（17）、2011（11）、2010（12）、2009（11）、2008（5）
- 难度分布：中等（12–15 词）、较难（16–22 词）、困难（23 词以上）；真题部分为中等 917 / 较难 656 / 困难 399
- 每句字段：`e` 英文原句、`c` 中文译文、`n` 词数、`d` 难度、`t` 结构标签、`s` 来源、`p` 真题标记、`y` 年份
- 真题判定规则：来源含「XX 卷」（如「2020·江苏卷·知识运用」「2018·新课标卷Ⅰ」），并排除模拟卷、期末/期中/月考、四六级套卷
- 结构标签（定语从句 / 状语从句 / 名词性从句 / 非谓语 / 被动语态 / 并列比较）由规则自动识别，仅作学习提示
- 语料整理自高考词库配套的中英对照例句与高考真题例句，仅用于学习

## 🚀 本地预览

```bash
./scripts/local-preview.sh
# 或
python3 -m http.server 8000
```

浏览器打开 <http://localhost:8000>。直接双击 `index.html` 也能用，但二维码分享与复制链接在 `file://` 下会受限。

## 🌐 部署到 GitHub Pages

```bash
git init && git add -A && git commit -m "init: gaokao sentences"
git remote add origin https://github.com/<用户名>/<仓库名>.git
git branch -M main && git push -u origin main
```

仓库 **Settings → Pages → Source 选 main / (root) → Save**，1 分钟后访问 `https://<用户名>.github.io/<仓库名>/`。

## ☁️ 部署到 Vercel

推到 GitHub 后，Vercel → New Project → 选仓库 → **Build Command 留空，Output Directory 留空** → Deploy。

或命令行：

```bash
export VERCEL_TOKEN=<你的 token>
./scripts/deploy-vercel.sh
```

## ⚠️ 关于「中译英」的联网说明

中译英使用在线翻译接口（有道翻译公开接口 `aidemo.youdao.com`，支持跨域），需要联网才能返回结果。若网络不可用或被拦截，页面会提示失败，并给出句库中语义最接近的参考译文供对照。练习记录、收藏、统计数据始终只保存在本机浏览器，不会上传。

## 📱 手机使用

电脑浏览器打开部署后的地址 → 点页面右上角分享按钮 → 手机扫码即可。练习数据保存在各自浏览器，换设备时用「数据」页面的导出 / 导入迁移。
